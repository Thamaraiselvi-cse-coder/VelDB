 VelDB — Database Management UI

VelDB is a SaaS-style database management interface designed to provide a clean and scalable user experience for handling data, queries, and analytics.



Live Prototype

https://woven-silo-36927761.figma.site



Features

* Dashboard with KPI cards and charts
* Tables management interface
* SQL Editor UI
* Import and Export workflows
* Domain dashboards (Finance, School, Hospital)
* Admin Panel
* Pricing Page
* Onboarding Flow
