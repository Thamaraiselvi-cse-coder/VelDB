# 🔤 Typography System

This document defines the typography scale for VelDB UI. All text styles must follow this system.

---

## Font Family
Primary Font → Inter, sans-serif  
Fallback → system-ui  

---

## Headings

### H1 (Page Title)
Font Size → 32px  
Font Weight → 700  
Line Height → 40px  

### H2 (Section Title)
Font Size → 24px  
Font Weight → 600  
Line Height → 32px  

### H3 (Subsection Title)
Font Size → 20px  
Font Weight → 600  
Line Height → 28px  

### H4 (Card Title)
Font Size → 16px  
Font Weight → 600  
Line Height → 24px  

---

## Body Text

### Body Large
Font Size → 16px  
Font Weight → 400  
Line Height → 24px  

### Body Medium
Font Size → 14px  
Font Weight → 400  
Line Height → 20px  

---

## Caption / Small Text
Font Size → 12px  
Font Weight → 400  
Line Height → 16px  

---

## Code / Monospace
Font Family → monospace  
Font Size → 13px  
Background → Light gray  
Usage → SQL queries, logs
