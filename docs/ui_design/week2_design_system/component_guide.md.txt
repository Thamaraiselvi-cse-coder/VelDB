# 🧩 Component Guide

This document defines usage rules for all UI components in VelDB. Developers must follow these rules strictly.

---

## Buttons

### Primary Button
- Background → Primary color
- Text → White
- Usage → Main actions (Create, Save)

### Secondary Button
- Background → Light gray
- Text → Dark
- Usage → Secondary actions

### Danger Button
- Background → Red
- Text → White
- Usage → Delete actions

---

## Input Fields

- Border → Light gray
- Focus → Blue border
- Error → Red border + message
- Placeholder → Light text

---

## Cards

- Background → White
- Border → Light gray
- Radius → 8px
- Shadow → Soft

Usage:
- Dashboard widgets
- Table containers

---

## Tables

- Header → Bold text + light background
- Rows → Alternating colors (optional)
- Hover → Highlight row

Usage:
- Database tables
- Query results

---

## Modals

- Center aligned
- Overlay background (dark transparent)
- Close button (top-right)

Usage:
- Export / Import
- Confirm actions

---

## Navigation

### Sidebar
- Fixed left
- Icons + labels
- Active → Highlight

### Topbar
- Title + actions
- Logout button (top-right)

---

## Alerts / Status

### Success
- Green background
- Used for success messages

### Error
- Red background
- Used for failures

### Warning
- Yellow background
- Used for cautions
