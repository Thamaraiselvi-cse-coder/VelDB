# 🎨 Color System

This document defines the color palette used across the VelDB UI. All developers must follow these colors strictly.

---

## Primary (Brand)
Primary 500 → #1E4D8C  
Primary 600 → #163E73  
Primary 100 → #DBEAFE  

## Secondary (Support UI)
Secondary 500 → #64748B  
Secondary 100 → #F1F5F9  

## Accent (Highlight / Actions)
Accent → #3B82F6  

## Success (Positive states)
Success → #22C55E  
Success Light → #DCFCE7  

## Warning (Caution)
Warning → #F59E0B  
Warning Light → #FEF3C7  

## Error (Critical)
Error → #EF4444  
Error Light → #FEE2E2  

## Neutral (UI base)
Background → #F8FAFC  
Card → #FFFFFF  
Border → #E2E8F0  

Text Primary → #1E293B  
Text Secondary → #64748B  
Text Disabled → #94A3B8
